# Multi-Project Repository

This repository contains two projects:

1. **TypeScript Todo App** - A feature-rich CLI todo application
2. **Hello World Java Maven Project** - A simple Java application demonstrating JSON parsing

---

## 📝 TypeScript Todo App

A beautiful, feature-rich command-line todo application built with TypeScript, featuring interactive prompts, colorful output, and persistent storage.

### Features

- ✨ Interactive CLI with beautiful UI using Chalk and Boxen
- 📊 Task management with priorities (low, medium, high)
- 🏷️ Tag-based organization
- 💾 Persistent storage with LowDB
- 📈 Statistics and filtering
- 🎨 Colorful and intuitive interface
- ⚡ Both interactive and command-line modes

### Cool Dependencies Used

- **chalk** - Terminal string styling for colorful output
- **inquirer** - Interactive command-line prompts
- **lowdb** - Simple JSON database for persistent storage
- **commander** - Command-line interface framework
- **date-fns** - Modern date utility library
- **boxen** - Create beautiful boxes in the terminal
- **ora** - Elegant terminal spinners
- **nanoid** - Unique ID generator

### Installation

```bash
npm install
npm run build
```

### Usage

#### Interactive Mode (Default)

Simply run without any arguments to enter interactive mode:

```bash
npm run dev
# or after building
npm start
```

#### Command Line Mode

Quick commands for power users:

```bash
# Add a todo
npm run dev -- add "Buy groceries" -d "Milk, bread, eggs" -p high -t "shopping,urgent"

# List all todos
npm run dev -- list

# List only pending todos
npm run dev -- list --pending

# List only completed todos
npm run dev -- list --completed

# Filter by priority
npm run dev -- list --priority high

# Complete a todo (use the ID from list command)
npm run dev -- complete <todo-id>

# Delete a todo
npm run dev -- delete <todo-id>

# Clear all completed todos
npm run dev -- clear

# View statistics
npm run dev -- stats
```

### Project Structure

```
src/
├── index.ts          # Main entry point with Commander CLI
├── cli.ts            # Interactive CLI using Inquirer
├── todoService.ts    # Business logic and CRUD operations
├── database.ts       # LowDB setup and configuration
├── display.ts        # Beautiful terminal output with Chalk & Boxen
└── types.ts          # TypeScript interfaces and types
```

### How It Works

1. **Persistent Storage**: Todos are stored in `~/.todo-app/db.json` using LowDB
2. **Interactive Mode**: Uses Inquirer for beautiful interactive prompts
3. **Command Mode**: Uses Commander for quick CLI operations
4. **Display**: Chalk and Boxen make the output colorful and organized
5. **IDs**: Each todo gets a unique ID generated by nanoid
6. **Dates**: date-fns formats all timestamps beautifully

## ☕ Hello World Java Maven Project

A simple Hello World Java application demonstrating JSON parsing using the `org.json` library.

## Project Structure

```
.
├── pom.xml
├── README.md
└── src
    ├── main
    │   └── java
    │       └── com
    │           └── example
    │               └── HelloWorld.java
    └── test
        └── java
```

## Dependencies

- **org.json:json** (version 20231013) - JSON parsing library

## Requirements

- Java 11 or higher
- Maven 3.6 or higher

## Building the Project

To compile the project, run:

```bash
mvn clean compile
```

## Running the Application

To run the application, use:

```bash
mvn exec:java
```

Or after building, you can run:

```bash
mvn clean package
java -cp target/hello-world-1.0-SNAPSHOT.jar com.example.HelloWorld
```

## What the Application Does

The HelloWorld application demonstrates:

1. **Hello World Message**: Prints a simple greeting
2. **JSON Object Creation**: Creates and parses a JSON object with person information
3. **JSON Array Handling**: Creates and iterates through a JSON array of objects
